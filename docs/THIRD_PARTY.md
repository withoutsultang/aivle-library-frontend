# 제3자 자료 확인

- 원본 프로젝트 LICENSE는 발견되지 않았으며 새 라이선스를 임의로 부여하지 않았습니다.
- 의존성 목록은 `dependency-licenses.json`에 기록했습니다. 설치된 패키지 메타데이터를 우선 사용하고 설치되지 않은 플랫폼 전용 패키지는 잠금 파일 메타데이터를 사용했습니다.
- MIT·Apache-2.0·BSD·ISC·BlueOak·Python·CC 계열 라이선스가 있습니다. 라이브러리 설치·번들 재배포 시 패키지의 라이선스 원문과 저작권·출처 고지를 유지해야 합니다. JSON 목록은 라이선스 원문을 대신하지 않습니다.
- `node_modules`와 빌드 결과는 업로드하지 않았습니다. 의존성을 배포할 경우 CC-BY-4.0 자료를 포함한 출처 표시 조건을 확인해야 합니다.
- Vite·React 로고 및 대체 표지 SVG가 원본 기록에 포함됩니다. 원본 README의 외부 첨부 이미지 1개는 과거 기록에 남겨두고 새 기본 README에는 사용하지 않았습니다.
- 과거 샘플 도서 데이터와 외부 표지 URL이 있습니다. 교육기관·팀, 이미지·데이터와 작성자 정보의 공개 허용 여부는 소유자의 2026-10-27 확인을 근거로 기록했습니다. 외부 제공자의 조건과 표지·본문의 권리는 각각 적용됩니다.
- 네이버·OpenAI 등 서비스 이름과 연동 코드는 해당 사업자의 후원이나 인증을 의미하지 않습니다. 서비스 자격증명과 유료 API 사용 권한은 이전되지 않습니다.
